# IoT Bazaar Manager
This is a project designed to streamline the management of electronic components for the IoT class by focusing on an exceptional user experience. The app’s core function revolves around using the device camera for QR code scanning to quickly check items in and out. This simple, intuitive workflow is the most critical aspect of the app, ensuring that students can easily log their transactions without a cumbersome process.

A key UX requirement is a transparent and clean interface. The app will use a backend database to maintain a real-time inventory and, more importantly, to provide each student with a clear view of exactly what they have borrowed. Students could log in with a pre-registered ID or their name.

# Planned Features
- QR Code Scanning: Use the device camera to scan QR codes on components for quick check
- User Authentication: Allow students to log in with a pre-registered ID or name.
- Inventory Management: Maintain a real-time inventory of components.
- User Dashboard: Provide students with a clear view of their borrowed items.
- Notifications: Send reminders for due dates on borrowed items.
- Item Guides: Include links to datasheets or tutorials for each component.
- Item Availability: Show real-time availability of components.
